3 · Title patterns that correlate with better performance

Across the 19 long-form essays (Shorts/update clips excluded), a few title habits track clearly with reach.

✅ What's working

PatternEvidence on this channel
A bold thesis / provocative claim, then a dash, then the game The six "[Statement] — [Game]" titles median 67 views/day: "Killing Nazis Isn't Woke — …Wolfenstein" (2,590 v/day), "You Are The Deep State — …" (240), "The Best Game I Ever Hated — …TLOU2" (75), "The Corporation Is the Monster — Alien: Isolation" (59).
Contrarian / argument hooks "Best Game I Ever Hated", "I Was Wrong About…", "Isn't Woke", "Brave Enough to Not Be…". Tension and reversal reliably out-earn neutral descriptions.
The big, high-search game name stated plainly The breakouts all name a game people are actively searching (Wolfenstein, Cyberpunk, The Last of Us, Silent Hill). The weakest essays either omit the game (Pragmata) or lead with a niche one.

❌ What's hurting

PatternEvidence on this channel
The "||" separator & series suffixes Long-form titles containing "||" median 3.5 views/day; those without median 9.7. Tails like "|| A Video Essay" and "- Intermission 0X" add no search value and truncate on mobile.
Hiding the subject "The Dad Game That Replaced Trauma With Tenderness" never says Pragmata — zero game-search capture despite the channel's best engagement.
"A Video Essay" as a title tag Appending the format ("|| A Video Essay") spends title real estate on a word nobody searches. Put the hook there instead.

Rule of thumb for this channel: [Provocative claim] — [High-search game name], no "||", no "Intermission", game named every time.

6 · Method & caveat

This report is built entirely from public YouTube Data API v3 signals: view count, like count, comment count, title, description, tags, duration and publish date. The normalized metric used throughout is views-per-day since publish, so videos of different ages compare fairly.

It has no access to YouTube Analytics — no click-through rate, impressions, traffic sources, audience retention or subscriber-conversion data. Every claim about why a video under- or over-performs (titling, thumbnail, discovery) is therefore an informed hypothesis from public signals, not a measured certainty. A high like/comment-to-view ratio paired with low views is strong circumstantial evidence of a packaging/discovery problem rather than a content one — but CTR and impressions would confirm it directly.

If a YouTube Analytics OAuth connection becomes available, this analysis would sharpen considerably: we could rank refresh candidates by actual CTR and impressions, measure whether a re-title/re-thumbnail actually moved the needle, and see where views come from (search vs. browse vs. suggested). Separately, the generation sandbox currently cannot reach YouTube's image CDNs, so the thumbnail visual read above is hypothesis-level until i.ytimg.com is allow-listed in the environment's network settings.
