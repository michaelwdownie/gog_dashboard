6Caveat on this analysis

This report is built only on public metrics available from the YouTube Data API v3: view count, like count, comment count, titles, tags, publish dates and durations. It has no access to the channel owner’s private analytics — click-through rate (CTR), impressions, average view duration or audience retention.

Because of that, every “why this works” claim here — especially the title and thumbnail recommendations — is an informed hypothesis, not a certainty. “Views/day” is used as an age-normalized proxy for performance, and a high like-ratio-to-views signal is used to infer “good content, weak discovery” — but only true CTR and retention data can confirm whether the title/thumbnail or the content itself is the lever.

Connecting a YouTube Analytics OAuth source would sharpen this dramatically: it would let future reports rank refresh candidates by actual CTR and impressions, measure whether a title change moved the needle, and spot retention cliffs inside videos. If that becomes available, wire it in.
