Pattern A — Lead with an argument, not a description. Every breakout opens with a claim or reframe ("The Corporation Is the Monster," "The Best Game I Ever Hated," "Killing Nazis Isn't Woke"). The under-performers open with a description or a mood. Make a provocative claim in the first 4–5 words.

Pattern B — The "[Claim] — [Game]" em-dash format wins. The four fastest-starting recent essays all use Provocative claim — Game/Franchise name. Adopt this as the house format. e.g. "Pragmata — The Dad Game That Replaced Trauma With Tenderness."

Pattern C — Name a searchable game/franchise up front. Winners put a high-volume search term (Wolfenstein, Alien: Isolation, Nine Sols) in the first half. The three biggest misses either hide the game name ("The Dad Game," EVE buried mid-title) or push it behind a suffix. Hiding the game name is the single most damaging habit on this channel.

Pattern D — Kill boilerplate suffixes and in-title hashtags. || A Video Essay, || Intermission 0X and #hashtags appear almost exclusively on under-performers. They eat the ~40 visible characters in search/suggested and add zero discovery value. Move series branding into the video and description, never the title.
